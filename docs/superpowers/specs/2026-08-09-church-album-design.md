# 교회앨범 (Church Photo Album) — 설계

- 작성일: 2026-08-09
- 대상: 빌드업교회 홈페이지 (`~/websites/buildup-church`, 정적 HTML, GitHub Pages)

## 배경 및 목적

교회 행사(수련회, 추수감사예배 등) 사진을 홈페이지에 앨범 형태로 게시한다. 기존 섹션(목회칼럼·
주간묵상·인터넷 주보)과 동일하게 순수 정적 HTML, 대화 기반 업데이트 패턴을 그대로 따른다.

## 구조

```
album/
├── index.html                          # 앨범 목록 (행사별 카드)
├── 2026-08-09-여름수련회/
│   └── index.html                      # 그 행사 사진 그리드 + 라이트박스(확대) 뷰어
└── images/
    └── 2026-08-09-여름수련회/
        └── (사진 파일들, 웹용으로 압축된 JPEG)
```

- 폴더명은 `YYYY-MM-DD-행사명영문슬러그` 형식 (column과 동일한 명명 규칙).
- 사이트 상단 내비게이션에 "교회앨범" 링크를 추가한다.

## 목록 페이지 (`album/index.html`)

- 행사별 카드 그리드: 대표사진(그 앨범의 첫 사진) + 행사명 + 날짜 + "사진 N장" 표시
- 최신 행사가 위로 오도록 날짜 내림차순 정렬
- 카드 클릭 시 해당 앨범 상세 페이지로 이동

## 상세 페이지 (`album/YYYY-MM-DD-행사명/index.html`)

- 사진을 그리드(격자) 형태로 배열 (한 행사당 10~30장 기준 설계, 그 이상도 그리드가 자연스럽게
  늘어나 대응 가능)
- 사진을 클릭하면 화면 전체를 덮는 라이트박스로 원본 크기에 가깝게 확대 표시
- 라이트박스에서 좌우 화살표(또는 스와이프)로 다음/이전 사진 이동, 닫기 버튼으로 그리드로 복귀
- 별도 외부 라이브러리 없이, 사이트의 기존 모바일 메뉴 토글과 같은 방식(순수 vanilla JS, 인라인
  `<script>`)으로 구현한다

## 사진 전달 및 업로드 흐름

1. 목사님이 이 대화창에 사진 파일을 직접 첨부(드래그 앤 드롭)하고 행사명·날짜를 말씀
2. 어시스턴트가 사진을 웹 게시에 적합한 크기로 압축(카드뉴스 제작 때와 동일한 방식 — 원본
   해상도를 유지하되 JPEG로 압축해 용량을 크게 줄임)한 뒤 `album/images/<행사폴더>/`에 저장
3. `album/<행사폴더>/index.html` 그리드 페이지를 생성하고, `album/index.html` 목록에 카드를
   새로 추가
4. 로컬 커밋 후, 실제 배포(`git push`)는 매번 목사님 승인을 받고 진행

폴더 경로를 직접 알려주시는 방식(예: "바탕화면 OO 폴더에 있어")으로도 전달 가능하다 — 이번
세션에서 설교 PPT를 이 방식으로 가져온 전례가 있다.

## 범위 밖

- 사진 업로드용 관리자 화면(별도 앱)은 만들지 않는다 — 대화 기반 업데이트로 충분하다는 판단
  (인터넷 주보와 동일한 결정).
- 사진 태그·검색 기능은 만들지 않는다 — 앨범(행사) 단위 탐색으로 충분하다.

## 테스트 방침

정적 HTML/JS이므로 자동화 테스트는 두지 않는다. 앨범을 새로 만들 때마다 브라우저에서 그리드
표시와 라이트박스 확대·좌우 이동·닫기 동작을 직접 확인한다.
